# Тестовое задание Руссмаркет

Ежедневная сводка для support-отдела: оформление и увольнение сотрудников, доставка карт.

Правила проверяют сроки и подтверждения в CRM. ИИ составляет сводку и выделяет расхождения в переписке. Сотрудник проверяет источники перед действием.

- [Решение в PDF](docs/russmarket-solution.pdf): схема, четыре случая, промпт и первый запуск.
- [Текст решения](docs/russmarket-solution.md).
- [Промпт](demo/prompt.txt).

## Запуск

Нужен Python 3.10 или новее. Устанавливать пакеты не требуется.

```sh
python3 demo/summary.py
python3 -m unittest discover -s demo -v
```

В `demo/cases.json` находятся данные из ТЗ, в `demo/result.json` сохранён результат правил. Дата 16.11.2026 выбрана условно: в ТЗ указан только понедельник, 10:00.

Прошли 12 тестов. Подключения к CRM, чатам и модели пока нет. Промпт используется отдельно; экономия времени ещё не измерялась.
